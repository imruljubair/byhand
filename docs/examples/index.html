Try it yourself

Choose a model source.

From Ollama

Visualize a compatible model already installed through Ollama.

byhand model --ollama llama3.2

From a local file

Read model metadata directly from a GGUF file on your Mac.

byhand model /path/to/model.gguf

From a public URL

Inspect a remote GGUF without downloading the full model first.

byhand model --url https://example.com/model.gguf

Export to HTML

Create a portable, self-contained interactive visualization.

byhand model --ollama llama3.2 --output html
