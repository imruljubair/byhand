Examples

See how a model works—in your terminal.

Load an Ollama or GGUF model, step through its architecture, and inspect the inputs, outputs, tensor shapes, and math behind each operation.

From model to math

Start an Ollama model in your terminal:

byhand model --ollama llama3.2

Select a screenshot to view it at full resolution.

HTML export

Example: llama3.2

Prefer a browser? Export the same visualization as an interactive HTML file:

byhand model --ollama llama3.2 --output html
↗

Excel export

Example: llama3.2 workbook

Prefer a spreadsheet? Explore the formula-driven model pipeline in Excel Online:

byhand model --ollama llama3.2 --output excel --step 5
