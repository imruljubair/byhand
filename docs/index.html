About

Visualization should reduce complexity, not add to it.

The terminal is a no-new-UI space: already installed, already familiar, and close to the models you run. byhand turns it into a navigable explanation without asking you to adopt another tool or workflow.

01

Start where you are

Run one command and stay in the terminal. There is no application to configure, workspace to organize, or interface to learn.

02

Reveal the model

Move operation by operation, connecting attention, equations, tensor shapes, and GGUF parameter sources.

03

Share when useful

The terminal stays the default. Export the same interactive explanation to a self-contained HTML file when you want a larger or shareable view.

Get started

One command. No new workspace.

Install on an Apple Silicon Mac, then visualize a compatible Llama-family model where you already work.

Read the docs 
curl -fsSL https://raw.githubusercontent.com/imruljubair/byhand/main/install.sh | sh

byhand model --ollama llama3.2
