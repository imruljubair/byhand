About

Models are easier to understand when you can see the work.

byhand turns GGUF metadata into a navigable explanation of a transformer model without loading or displaying its weight values.

01

Follow the model

Move operation by operation through attention, normalization, feed-forward layers, and residual paths.

02

Inspect the math

Open an Operation Explainer to connect equations, tensor shapes, selected cells, and GGUF parameter sources.

03

Choose your canvas

Explore inside the terminal or export the complete interactive view as a self-contained HTML file.

Get started

One command from model to map.

Install on an Apple Silicon Mac, then open a compatible Llama-family model from Ollama.

Read the docs 
curl -fsSL https://raw.githubusercontent.com/imruljubair/byhand/main/install.sh | sh

byhand model --ollama llama3.2
