How it works

From model file to understandable math.

01

Load a model

Point byhand at an Ollama model, a local GGUF file, or a public GGUF URL.

byhand model /path/to/model.gguf
02

Follow the computation

Move through attention, normalization, residual paths, tensor shapes, equations, and parameter sources.

03

Choose your depth

Survey the full architecture, focus on one operation, or trace how calculated values flow through the pipeline.

Get started

One command. No new workspace.

Install on an Apple Silicon Mac, then open a compatible Llama-family model where you already work.

curl -fsSL https://raw.githubusercontent.com/imruljubair/byhand/main/install.sh | sh

byhand model /path/to/model.gguf

What it reads: GGUF metadata and tensor descriptors—not tensor weight values.

The current standalone release supports macOS on Apple Silicon and is distributed unsigned outside the Mac App Store. Installation details
